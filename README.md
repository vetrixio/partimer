# 打工人計時器（partimer）

住在系統匣／選單列的工時計時器：選專案、按 START，做完按 STOP，月底匯出 CSV 對帳。
支援 macOS（Apple Silicon 與 Intel）、Windows 10/11、Ubuntu 24.04 以上；其他 Linux 不保證能用。

## 下載與安裝

到 [Releases](https://github.com/vetrixio/partimer/releases) 下載最新版本，檔名都是英文：

| 平台 | 檔案 | 安裝方式 |
|---|---|---|
| macOS | `partimer_<版本>_darwin_universal.dmg` | 打開 `.dmg`，把「打工人計時器」拖進「應用程式」資料夾。 |
| Windows | `partimer_<版本>_windows_x64-setup.exe` | 執行安裝程式，照畫面按「下一步」。 |
| Ubuntu | `partimer_<版本>_linux_amd64.deb` | `sudo apt install ./partimer_<版本>_linux_amd64.deb` |
| Ubuntu（免安裝） | `partimer_<版本>_linux_amd64.AppImage` | `chmod +x partimer_*.AppImage` 後直接執行。 |

安裝後打開 app **不會跳出任何視窗**，它在系統匣／選單列多了一個小盆栽圖示，這是正常的。

### 第一次開啟被擋住怎麼辦

這個 app 沒有購買程式碼簽章憑證，第一次開啟時系統會警告，這是預期的。

**macOS（15 以上）**

1. 在「應用程式」資料夾雙擊「打工人計時器」，出現「無法打開」的訊息時按「完成」。
2. 打開「系統設定 → 隱私權與安全性」，捲到最下面的「安全性」，找到「已阻擋『打工人計時器』……」，按「強制打開」。
3. 輸入密碼確認後，再按一次「強制打開」。之後就能正常開啟，不會再問。

如果訊息是「已損毀，無法打開」，請打開「終端機」執行下面這行（解除下載隔離），再重新開啟：

```sh
xattr -dr com.apple.quarantine "/Applications/打工人計時器.app"
```

**Windows**

出現藍色的「Windows 已保護您的電腦」（SmartScreen）時，按「其他資訊」→「仍要執行」。

**Ubuntu**

- 系統匣圖示需要 AppIndicator 擴充套件。Ubuntu 24.04 預設已安裝並啟用「Ubuntu AppIndicators」；如果頂列看不到小盆栽，打開「擴充功能」（Extensions）app 確認它是開啟的，或在終端機執行 `gnome-extensions list --enabled | grep -i appindicator` 檢查。
- 終端機指令是 `partimer`。

### 解除安裝

- **macOS**：結束 app（選單列圖示按右鍵 →「結束」），把「應用程式」裡的「打工人計時器」丟到垃圾桶。
- **Windows**：「設定 → 應用程式 → 已安裝的應用程式」找到「打工人計時器」→「解除安裝」。
- **Ubuntu**：`sudo apt remove partimer`；AppImage 直接刪掉檔案即可。

解除安裝**不會刪除你的資料**。要連資料一起刪，請再手動刪掉下面「資料放在哪裡」的資料夾。

## 基本操作

- **打卡面板**：點系統匣／選單列的小盆栽（Ubuntu 是點圖示後選「打開面板」）。
  1. 選專案（依客戶分組；最後一項「＋ 新增專案…」可直接新增）。第一次使用時先填客戶名與專案名、按「建立」。
  2. 填「標題」和「內容」（以「- 」開頭的行會顯示成項目符號），按 **START** 開始計時。
  3. 中途休息按 **PAUSE**，回來按 **RESUME**；做完按 **STOP**。
- **儲存文字**：計時中打的標題與內容先放在記憶體，按 **Ctrl+S**（macOS **⌘S**）或「儲存」才寫入檔案；STOP、切換專案、結束 app、登出或關機時也會自動存好。STOP 之後，下一筆會沿用標題、內容是空的。
- **計時中換專案**：直接在選單選別的專案，確認後會結束目前這筆、立刻開始新專案的計時。
- **今日紀錄**：面板下方列出今天的紀錄與今日總計，點一筆可以打開紀錄視窗編輯它。
- **收起面板**：按 Esc、再點一次圖示，或再按一次快捷鍵。面板收起時打到一半的文字不會不見。
- **浮動小時鐘**：計時中在螢幕右上角顯示一個半透明的小時鐘（Windows、Ubuntu 預設開啟；macOS 選單列本來就會顯示時間，預設關閉，可在設定打開）。可以拖到任何位置，下次會出現在同一個地方；點一下開關打卡面板。
- **提醒**：計時超過 12 小時會提醒「是不是忘了停？」，可以直接填實際結束時間；設定裡可以打開「整點提醒」，每滿一小時通知一次。
- **再開一次 app**（例如從應用程式清單再點一次）不會開第二個，而是叫出打卡面板。

### 快捷鍵

| 動作 | Windows／Ubuntu | macOS |
|---|---|---|
| 叫出／收起打卡面板（全域） | Ctrl+Alt+P | ⌃⌥P（Ctrl+Option+P） |
| 儲存標題與內容 | Ctrl+S | ⌘S |
| 收起面板、關閉編輯視窗 | Esc | Esc |

快捷鍵被其他程式占用時，設定視窗會用紅字說明。

**Ubuntu 的 Wayland（預設登入方式）不允許 app 註冊全域快捷鍵**，請改用系統的自訂快捷鍵：

1. 打開「設定 → 鍵盤 → 檢視及自訂快捷鍵 → 自訂快捷鍵」，按「＋」。
2. 名稱隨意（例如「打卡面板」），指令填 `partimer`，快捷鍵按你想要的組合（例如 Ctrl+Alt+P）。

因為 app 只會執行一個，這個快捷鍵的效果就是叫出打卡面板。

## 紀錄、設定與 CSV 匯出

- **紀錄視窗**（面板下方「紀錄」或系統匣選單）：依月份、客戶、專案篩選，左邊是月總計與各專案小計，右邊依日期列出每筆紀錄。點一筆可以編輯開始／結束時間、暫停分鐘數、標題與內容或刪除；「新增紀錄」可以補登。
- **匯出 CSV**：在紀錄視窗按「匯出 CSV」，會匯出目前篩選的月份（檔名預設 `partimer-YYYY-MM.csv`）。檔案是 UTF-8 含 BOM，Excel 直接打開中文正常。欄位：日期、客戶、專案、開始、結束、分鐘、小時、暫停分鐘、標題、內容；計時中的那筆不會匯出。
- **設定視窗**：開機自動啟動、浮動小時鐘（開關、透明度、沒在計時時也顯示）、整點提醒；客戶與專案的改名、顏色、封存與刪除；「打開資料夾」直接打開資料所在的資料夾。
  - 封存的專案不會出現在面板的選單，但紀錄仍保留、仍會出現在紀錄視窗。
  - 刪除客戶或專案會一併刪掉它的紀錄，刪除前會告訴你會刪掉幾筆、共多少時間。

## 資料放在哪裡

| 平台 | 資料夾 |
|---|---|
| macOS | `~/Library/Application Support/partimer/` |
| Windows | `%APPDATA%\partimer\`（通常是 `C:\Users\<你>\AppData\Roaming\partimer\`） |
| Ubuntu | `~/.local/share/partimer/` |

資料夾裡有：

| 檔案 | 用途 |
|---|---|
| `data.json` | 所有客戶、專案、紀錄與設定 |
| `backups/data-YYYY-MM-DD.json` | 每天的自動備份，保留最近 30 份 |
| `data.corrupt-YYYYMMDD-HHMMSS.json` | 資料檔壞掉時保留的原檔 |
| `activity.log` | 活動紀錄（見下面） |

### 備份與還原

- **自動備份**：每天第一次開啟 app 時（app 一直開著跨日的話，是跨日後第一次存檔前），把 `data.json` 複製一份到 `backups/`，保留最近 30 天。
- **自動還原**：`data.json` 壞掉或不見時，app 會自動從最新一份可讀的備份還原，壞掉的檔案改名為 `data.corrupt-…json` 保留，面板上會顯示提示。
- **手動還原到某一天**：
  1. 結束 app（系統匣圖示 →「結束」，或面板下方「結束 app」）。
  2. 把 `data.json` 改名保留（例如 `data.json.old`）。
  3. 把 `backups/` 裡想要的那天的 `data-YYYY-MM-DD.json` 複製到資料夾裡，改名為 `data.json`。
  4. 重新開啟 app。
- **換電腦或自己備份**：結束 app 後複製整個資料夾即可；放回新電腦的同一個位置再開 app。

### 活動紀錄（activity.log）

每次開始、暫停、繼續、結束、儲存、編輯、補登、刪除、切換專案、從備份還原等動作都會追加一行，記錄時間、動作、紀錄編號，以及當時標題與內容的**字數**，**不記文字內容**。用途是事後查證：例如懷疑某筆紀錄被改掉或少算時間時，可以對照當時發生了什麼。檔案可以用任何文字編輯器打開，刪掉也不影響 app。

## 已知限制

- **Windows 的系統匣圖示旁不能顯示文字**，所以計時時間顯示在浮動小時鐘與圖示的滑鼠提示文字；不想看到小時鐘可以在設定關掉。
- **獨佔全螢幕的遊戲會蓋過浮動小時鐘**；一般全螢幕影片、簡報能不能看到則依系統而定。
- **Ubuntu Wayland 下全域快捷鍵無效**，請照上面「快捷鍵」的方式設定系統自訂快捷鍵。
- Ubuntu 頂列圖示旁能不能顯示時間要看桌面環境；看不到時請用浮動小時鐘。
- 沒有程式碼簽章，第一次開啟要照上面的步驟允許一次。
